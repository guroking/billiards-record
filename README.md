# 🎱 대학별 당구 전적판 (Billiards Record)

🔗 **웹 서비스 바로가기:** [https://billiards-record.onrender.com/](https://billiards-record.onrender.com/)

대학교 친구들끼리 당구 전적을 기록하고 랭킹을 관리할 수 있는 실시간 웹 서비스입니다. 복잡한 회원가입 없이 학교별 공용 비밀번호를 통해 누구나 쉽고 빠르게 경기 결과를 저장할 수 있습니다.

## ✨ 핵심 특징 (Key Features)

* **🚀 무한한 확장성 (대학별 독립 라우팅)**
  단일 데이터베이스를 사용하되, 대학교 코드(예: `?uni=kmou`)를 기준으로 데이터를 분리했습니다. 이를 통해 새로운 대학교가 추가되더라도 코드 수정 없이 즉각적으로 독립된 전적판을 제공할 수 있습니다.
* **📱 모바일 친화적인 UI/UX**
  당구장 특성상 PC보다는 스마트폰을 통한 접근이 압도적으로 많습니다. 이를 고려하여 하단 네비게이션 탭, 직관적인 Select Box, 부드러운 토스트 알림, 그리고 기기 설정에 맞춘 자동 **다크모드**를 지원하는 모던하고 깔끔한 앱(App) 형태의 디자인을 적용했습니다.
* **🏆 Elo 레이팅 기반 랭킹 시스템**
  단순한 다승이나 승률 기반이 아닌, 체스나 E-스포츠에서 주로 사용하는 Elo 레이팅 점수제(K-factor 32)를 도입했습니다. 강자를 이기면 점수가 크게 오르고 약자를 이기면 적게 오르므로 훨씬 신뢰도 높은 명예의 전당이 구성됩니다.
* **🛡️ 보안 및 추적**
  공용 비밀번호는 `bcrypt`로 안전하게 암호화되어 DB에 저장되며, 분탕 유저를 대비해 경기 기록 시 보이지 않는 백그라운드에서 접속자의 IP 주소와 User-Agent를 함께 로깅합니다.

## 📖 사용 방법 (How to Use)

### 1. 대학교 입장
* 메인 접속 화면에서 본인이 속한 대학교를 선택하고 입장 버튼을 누릅니다.

### 2. 선수 등록 (최초 1회)
* 하단 **[🏠 홈]** 탭의 '선수 등록' 영역에서 이름을 입력하고 등록합니다.
* 등록된 선수는 기본 명예의 전당 점수 **1200점**을 부여받으며, 즉시 선수 명단 드롭다운에 노출됩니다.

### 3. 경기 결과 기록
* 당구 경기가 끝난 후 **[🏠 홈]** 탭에서 **승리 선수**와 **패배 선수**를 선택합니다.
* 게임 종목(4구, 3쿠션, 포켓볼)을 선택합니다.
* 학교별 **공용 비밀번호**를 입력하고 [결과 저장하기]를 누르면 Elo 점수와 승률이 즉시 계산되어 반영됩니다.

### 4. 랭킹 및 타임라인 확인
* **[🏆 랭킹]** 탭: 현재 우리 학교의 1등부터 꼴등까지의 실시간 Elo 점수와 누적 승률을 확인합니다.
* **[🕒 기록]** 탭: 누가 누구를 이겼는지 최신 경기 순으로 타임라인이 제공됩니다.

## 🛠 기술 스택 (Tech Stack)

* **Frontend:** HTML5, CSS3 (CSS Variables), Vanilla JS, Fetch API
* **Backend:** Node.js, Express.js, bcrypt (비밀번호 암호화)
* **Database:** PostgreSQL (pg 모듈)
* **Deployment:** Render (Web Service & Free PostgreSQL)
